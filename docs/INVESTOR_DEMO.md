# Investor presentation

Narrative: **smart bicycle sharing + city conquest + activity + community + persistent rewards + business intelligence**. Disclose simulation boundaries before showing metrics; no figures represent real commercial performance.

1. Show the landing page, live map and database demo totals.
2. Sign in as rider, reserve at Amir Temur Square and demonstrate bike identification/simulated lock release.
3. Advance the server-controlled loop, pause/reload and finish at valid parking.
4. Show earned XP, joined mission completion, territory influence, passport stamps and achievement. Redeem persistent loyalty credit.
5. Sign in as admin, inspect the rental in analytics, edit the fleet and publish a mission. Confirm user visibility and the audit trail.
6. Open investor overview; separate demo operations from projections. Change conservative/base/optimistic rides-per-bike assumptions and acquisition/maintenance costs.
7. Sign in as business admin; inspect aggregate participation/impact and create a collective challenge.
8. State next milestones: PostgreSQL runtime checks, physical locks/payments/email, translations, automated seasons and real-time team battles.

Both servers must run together. Core assets are local; street tiles have an explicit schematic fallback. The simulation takes 18 clicks and represents 27 minutes. Screenshots live in docs/screenshots. Browser tests add rides/missions/rewards, so totals increase after verification. A fresh isolated demo database is optional for a clean presentation.
